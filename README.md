# 🍄 Portobello Timer

A playful twist on the classic **Pomodoro technique** — perfect for those who aren’t fans of tomatoes!

🔗 [Live Demo](https://rahul-lal.github.io/portobello-timer/)

## 🚀 Features

* Customizable **25/5 Pomodoro sessions**
* Alarm sound when time runs out ⏰
* Background image and themed design 🍄
* Responsive layout for desktop and mobile

## 🛠️ Tech Stack

* **HTML5** – structure
* **CSS3** – styling
* **JavaScript (Vanilla)** – timer logic and UI updates
